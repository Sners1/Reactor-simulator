# 🏭 Reactor Simulator — симулятор ядерного реактора

**Reactor Simulator** — это симулятор ядерного реактора с проработанной **физикой** и **экономикой**.
Управляйте реактором, следите за ксеноновым отравлением, пустотами и износом модулей,
зарабатывайте кредиты, модернизируйте оборудование и не допустите расплава активной зоны.

---

## 📋 Системные требования

- **Python 3.10 или новее**
- Windows, Linux или macOS
- Клавиатура и мышь (управление через интерфейс)

---

## 🚀 Установка и запуск

### Шаг 1. Откройте терминал в папке с игрой

**Windows:**

1. Откройте папку с игрой в Проводнике.
2. Щёлкните по **адресной строке** вверху, введите `cmd` и нажмите **Enter** — консоль откроется сразу в нужной папке.

Либо: нажмите **Shift + правая кнопка мыши** в пустом месте папки → **«Открыть окно терминала здесь»**.

**Linux / macOS:**

1. Откройте терминал.
2. Перейдите в папку с игрой командой `cd`:

    cd путь/к/папке/с/игрой

> 💡 Проверьте, что вы в нужной папке: команда `dir` (Windows) или `ls` (Linux/macOS) должна показать файл `main.py`.

### Шаг 2. Установите зависимости

Все нужные библиотеки перечислены в файле **`requirements.txt`** (сейчас это `PySide6`).
Установите их одной командой:

    pip install -r requirements.txt

Если команда `pip` не найдена, используйте:

    python -m pip install -r requirements.txt

### Шаг 3. Запустите игру

Находясь в той же папке, выполните:

    python main.py

> 💡 Если команда `python` не срабатывает, попробуйте `py main.py` (Windows) или `python3 main.py` (Linux/macOS).

Готово — откроется главное меню игры. ⚛️

---

## 💾 Сохранения

Прогресс, **кредиты** и **износ модулей** сохраняются в папке **`saves`**.

> ⚠️ **Не удаляйте папку `saves`** — вместе с ней пропадёт весь ваш прогресс.

Папка создаётся автоматически при первом запуске, если её нет.

---

## 🎮 Кратко об игре

- **Физика** — реактивность, температура, давление, ксеноновое отравление, пустоты.
- **Экономика** — зарабатывайте кредиты, покупайте модули, стройте новые реакторы.
- **Износ** — модули изнашиваются и требуют обслуживания.
- **Уровни реализма** — *Аркада*, *Нормал* и *Хардкор*.
- **Обучение** — встроенные подсказки для первых шагов.

Приятной игры и стабильной критичности! ⚛️
